## 📖 About

Mob Spawner Locator scans nearby chunks for mob spawner blocks, drawing ESP boxes and listing their type and coordinates in the HUD.

---

## ✨ Features
<a name="features"></a>

- **ESP Boxes** — coloured boxes around each spawner through terrain.
- **Type Label** — zombie, skeleton, spider, blaze, cave spider, silverfish.
- **Distance Sort** — nearest spawner listed first.
- **Activate Range** — shows the 16-block activation radius circle.
- **AFK Spot Suggester** — calculates ideal AFK platform position.
- **Toggle Key** — quick on/off.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
